Privacy Policy

Last Updated: October 8, 2026

The AI-CI Automated Test Runner ("the Application") provides automated headless-browser testing utilities within the Anna AI OS environment. This privacy documentation outlines our data processing standards.

1. Data Processing and Scope

The audit runs in an isolated headless browser on the host that runs the Application's engine. When an automated UI diagnostic check is executed, the following technical data point aggregates are processed:

  • Target URL addresses that you enter when running an audit.
  • Browser console diagnostic statements and unhandled functional stack traces.

2. Third-Party and AI Processing

If runtime exceptions are captured during an audit, the error messages and a limited sample of console output may be sent for AI diagnosis. This happens in one of two ways: to the Google Gemini API using a key you configure for the engine, or, if no key is configured, to Anna's built-in AI service. Do not audit pages whose console output contains sensitive or personal data. We do not intentionally collect personally identifiable information, user profiles, or database records.

3. Data Storage Controls

The Application does not persist system data records, execution logs, or source code states to any centralized external server. All state memory is strictly structural and terminates immediately upon completion of the script cycle run.
