Privacy Policy

Last Updated: October 8, 2026

The AI-CI Diagnostic Agent ("the Application") provides local, automated browser testing utilities within the Anna AI OS sandbox environment. This privacy documentation outlines our data processing standards.

1. Data Processing and Scope

The Application operates locally within your designated sandboxed environment. When an automated UI diagnostic check is executed, the following technical data point aggregates are processed:

  • Target URL addresses provided explicitly during execution execution variables.
  • Browser console diagnostic statements and unhandled functional stack traces.

2. Third-Party API Orchestration

In the event that runtime exceptions or unhandled failures are captured during a browser audit loop, technical error strings are forwarded securely to the Google Gemini API framework via your configured environment credentials. No personally identifiable credentials, structural user profiles, or raw database records are transmission-eligible.

3. Data Storage Controls

The Application does not persist system data records, execution logs, or source code states to any centralized external server. All state memory is strictly structural and terminates immediately upon completion of the script cycle run.
